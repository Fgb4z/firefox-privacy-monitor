This page tests if different types of requests, made using various browser mechanisms, are getting blocked.
To test your request blocking solution please add bad.third-party.site domain to your blocklist.
Start the test Download the results
HTML
- script - Try loading a JavaScript file using <script> element.
- style - Try loading a CSS file using <link> element.
- img - Try loading an image using <img> element.
- picture - Try loading an image using <picture> element.
- object - Try loading an image using <object> element.
- audio - Try loading an audio file using <audio> element.
- video - Try loading a video file using <video> element.
- iframe - Try loading a frame using <iframe> element.
CSS
- import - Try loading a CSS file using @import url(…).
- font - Try loading a font file using @font-face {src: url(…)}.
- background - Try loading an image using background: url(…).
JS
- websocket - Try connecting to a WebSocket.
- server-sent-events - Try connecting to an EventSource.
- fetch - Try requesting data using fetch(…).
- xmlhttprequest - Try requesting data using XMLHttpRequest.
- sendBeacon - Try sending data using sendBeacon.
Other
- favicon - Try loading an image using <link rel="shortcut icon" ….
- iframe-fetch - Try requesting data from within a first-party iframe.
- iframe-fetch-depth-2 - Try requesting data from two frames deep (iframe within an iframe).
- webworker-fetch - Try fetching data from within a WebWorker.
- serviceworker-fetch - Try fetching data from within a ServiceWorker.
- csp-report - Try sending data via CSP report.
- redirected-fetch - Try requesting tracker via redirect through a safe domain.
